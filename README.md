# Pokémon Search - Favorites

[![wakatime](https://wakatime.com/badge/user/b2c18339-9206-4f69-b04a-55ee4aead61a.svg)](https://wakatime.com/@b2c18339-9206-4f69-b04a-55ee4aead61a)

A system for searching, filtering, and bookmarking Pokémon TCG cards.

### Features

- Search: Search by name or set number.
- Favorites: Saves favorite cards to browser storage (localStorage).
- Filters: Filter by category and texture; option to display only favorite cards.
- Sorting: Sort by price or name.
- Details: Displays additional information and prices when clicking on a card.
- Sets: Search for Pokémon cards by set.
- Min/Max Prices: Search for cards based on minimum and maximum prices.

### Other
- Hovering over a card triggers a 3D holographic effect.
- Zoom in on cards.
